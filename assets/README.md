# Cinematic audio assets

The video generators automatically look for these optional files in this folder:

- `background_music.mp3` — a licensed/owned instrumental cinematic music bed. It is mixed quietly under narration in both Shorts and long videos.
- `intro_impact.wav` — an optional short (about 1–1.5 second) impact/whoosh sound for the opening hook.

Use only audio you created, licensed for commercial YouTube use, or otherwise have permission to monetize. Keep the license/receipt with your project records.

If either file is missing, the generators continue without it. No API key is needed.
